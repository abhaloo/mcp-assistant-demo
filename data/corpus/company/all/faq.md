# Bloomfield Print Works — FAQ (Demo)

## What products do we print?

We print brochures, business cards, banners, and packaging for fictional demo customers across Tanzania.

## How do I look up an invoice?

Use the billing system with `view invoice` permission. This demo API answers structured invoice questions when business query mode is enabled.

## What is our entity name?

The demo entity is **Bloomfield Print Works** (entity id 1). All customers and users in the bundled database are fictional.
